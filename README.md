Дневник трейдера XAUUSD

Бесплатный журнал сделок по золоту для начинающих.
Записывайте сделки, смотрите свою статистику и растите к цели.

Установка на телефон
iPhone: откройте ссылку в Safari → «Поделиться» → «На экран Домой».
Android: откройте ссылку в Chrome → меню ⋮ → «Установить приложение».
Журнал появится на рабочем столе и будет работать даже без интернета.

Как пользоваться
При первом запуске укажите депозит и цель.
После каждой сделки нажимайте «+» и заполняйте: позиции, стоп, результат, скриншот.
Честно отмечайте эмоции и ошибки — так журнал покажет, что мешает расти.
Раз в неделю заглядывайте в «Обзор» и разбирайте статистику.

Важно!
Ваши данные хранятся только на вашем телефоне — их никто не видит.
Раз в неделю нажимайте Настройки → «Сохранить копию», чтобы не потерять журнал
и иметь возможность перенести его на другое устройство.
