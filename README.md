# Дневник трейдера XAUUSD

Журнал сделок по золоту для начинающих трейдеров. Работает в браузере и устанавливается
на телефон как приложение. Сервер не нужен: все данные хранятся на устройстве пользователя.

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | Само приложение |
| `manifest.json` | Название, иконка и цвет при установке на телефон |
| `sw.js` | Офлайн-режим (приложение открывается без интернета) |
| `icons/` | Иконки приложения |

## Как опубликовать на GitHub Pages

1. Зарегистрируйтесь на https://github.com
2. Нажмите «+» вверху справа → **New repository**.
   Название, например, `trader-journal`. Выберите **Public**. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
4. Перетащите в окно **все файлы и папку `icons`** (сначала распакуйте архив).
   Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В блоке *Branch* выберите `main` и папку `/ (root)`, нажмите **Save**.
6. Через 1–3 минуты сверху появится ссылка вида `https://ВАШ-НИК.github.io/trader-journal/`.
   Это и есть адрес приложения.

## Как обновить приложение

1. Загрузите новый `index.html` тем же способом (Add file → Upload files) — он заменит старый.
2. В файле `sw.js` поменяйте `xau-journal-v1` на `xau-journal-v2` (потом v3 и т. д.).
3. У пользователей обновление подтянется при следующих открытиях. Их сделки не пропадут.

## Как поставить свой бренд (для лид-магнита)

В `index.html` найдите блок `CONFIG` в начале скрипта и заполните:

```js
const CONFIG = {
  brandName:  'Gold Academy',
  brandHandle:'@gold.trader',
  brandLink:  'https://instagram.com/gold.trader',
  brandText:  'Обучение торговле золотом с нуля'
};
```

Ссылка появится внизу экрана «Обзор» и в настройках.

## Важно знать

- Данные каждого пользователя хранятся только в его браузере. Вы их не видите.
- При очистке данных браузера журнал пропадёт, поэтому в приложении есть «Сохранить копию»
  и «Загрузить копию». Через копию же переносят журнал на другое устройство.
- На iPhone приложение нужно открывать в Safari и добавить на экран «Домой».
